# Pet Shop AUmigos
Sistema web desenvolvido para um pet shop, com objetivo de facilitar o cadastro e o controle de clientes e seus animais.

# Funcionalidades

- Cadastrar, listar, editar e excluir clientes;
- Cadastrar, listar, editar e excluir animais;
- Associar cada animal a um cliente;
- Visualizar os animais de cada cliente.

# Tecnologia Utilizadas
- PHP
- MySQL
- HTML e CSS
- Bootstrap
- XAMPP

# Banco de dados
O sistema utiliza duas tabelas: 
- clientes
- animais

A tabela animais possui uma chave estrangeira que faz o relacionamento com a tabela clientes.

Um cliente pode possuir vários animais, mas cada animal possui apenas um responsável.

# Objetivo da Atividade
O objetivo é desenvolver um sistema CRUD utilizando PHP e MySQL, trabalhando com cadastro, edição, exclusão, listagem e relacionamento entre clientes e animais.
